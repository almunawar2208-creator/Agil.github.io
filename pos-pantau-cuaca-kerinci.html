Catatan Sistem

Data di atas adalah simulasi untuk keperluan demo/sidang. Alur aslinya: sensor Anemometer + BME280 di puncak → dikirim via LoRa SX1278 ke node penerima di basecamp → disimpan ke database → ditampilkan di sini secara real-time. Saat kondisi ekstrem terdeteksi (angin kencang / suhu ekstrem), sistem otomatis pindah ke Mode Darurat (interval kirim 5 menit) sesuai rancangan flowchart.
